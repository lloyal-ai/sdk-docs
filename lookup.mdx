<h2 id="floors">Runtime and hardware</h2>
<p><strong>Node 24 or newer</strong>, declared by the CLI and by every scaffolded project. <strong>16 GB of RAM or unified memory</strong> is the working recommendation: the recommended trunk model is 2.6 GB of weights, the <code>research</code> template adds a 630 MB reranker, and the remainder covers KV at the recommended 32k context plus the OS and whichever surface is running.</p>

<div class="section-kicker">Retrieval</div>
<h2 id="scoring">Retrieval and scoring</h2>
<p>One cross-encoder serves four roles. Three different queries are in play — the per-call tool query, the per-agent task, and the original research query — and conflating them produces wrong scores.</p>
<div class="code-frame"><div class="code-label">TypeScript</div><pre><code>interface EntailmentScorer {
  scoreEntailmentBatch(texts: string[]): Promise&lt;number[]&gt;;
  scoreRelevanceBatch(texts: string[], localQuery: string): Promise&lt;number[]&gt;;
  scoreSimilarityBatch(reference: string, texts: string[]): Promise&lt;number[]&gt;;
  shouldProceed(score: number): boolean;
}

interface ScorerReranker {
  scoreBatch(query: string, texts: string[]): Promise&lt;number[]&gt;;
}</code></pre></div>
<div class="table-wrap"><table><thead><tr><th>Method</th><th>Scores against</th><th>Used at</th></tr></thead><tbody>
<tr><td><code>scoreEntailmentBatch</code></td><td>the original query</td><td>content prefill boundaries</td></tr>
<tr><td><code>scoreRelevanceBatch</code></td><td><code>min(local, original)</code></td><td>exploit mode, when pressure tightens focus</td></tr>
<tr><td><code>scoreSimilarityBatch</code></td><td>an arbitrary reference</td><td>echo detection at delegation</td></tr>
<tr><td><code>shouldProceed</code></td><td>the floor</td><td>the gate itself</td></tr>
</tbody></table></div>
<p>The score is a <strong>logit-diff</strong> — <code>logit(yes) − logit(no)</code>, unbounded, with the sign carrying the meaning. <code>Source._entailmentFloor</code> defaults to <strong>0</strong>: a hit passes when the cross-encoder leans yes. Raise it for noise-heavy corpora, lower it for sparse ones.</p>
<div class="code-frame"><div class="code-label">TypeScript</div><pre><code>abstract class Source&lt;TCtx = unknown, TChunk = unknown&gt; {
  abstract readonly name: string;
  abstract get tools(): Tool[];
  protected _reranker: ScorerReranker | null;
  protected _entailmentFloor: number;          // default 0
  createScorer(originalQuery: string): EntailmentScorer;
  promptData(): Record&lt;string, unknown&gt;;
  getChunks(): TChunk[];
}</code></pre></div>
<p><code>promptData()</code> is what the per-spawn skill template reads, so an agent learns what kind of source it holds before it searches.</p>

<div class="section-kicker">Authority</div>
<h2 id="consent">Consent and protected tools</h2>
<p>The gate for consequential actions runs at DISPATCH, inside the agent runtime — below any application or interface code that could misreport it.</p>
<div class="code-frame"><div class="code-label">TypeScript</div><pre><code>interface GrantStore {
  has(toolName: string): Operation&lt;boolean&gt;;
  grant(toolName: string): Operation&lt;void&gt;;
  revoke(toolName: string): Operation&lt;void&gt;;
}

GrantStoreCtx  // createContext&lt;GrantStore&gt;('lloyal.grantStore')</code></pre></div>
<p><strong>Fail-closed.</strong> A tool marked <code>protected</code> is denied unless the session holds a grant, and no grant store configured means every protected tool is denied. Credentials never enter the model's context — the model can trigger a gated call, never see or replay the secret.</p>
<p class="path-label">packages/agents/src/grant-store.ts · context.ts</p>

<div class="section-kicker">Diagnosis</div>
<h2 id="traces">Trace events</h2>
<p>Pass a writer to <code>initAgents</code> to capture the inference graph as newline-delimited JSON. With none passed, <code>NullTraceWriter</code> makes every trace call a no-op at zero cost. Events form a tree through <code>parentTraceId</code>; the <code>TraceParent</code> context connects inner pools to the tool dispatch that spawned them without manual wiring.</p>
<div class="table-wrap"><table><thead><tr><th>Event</th><th>Captures</th></tr></thead><tbody>
<tr><td><code>scope:open</code> / <code>close</code></td><td>named boundaries with duration — pools, tools, spines</td></tr>
<tr><td><code>prompt:format</code></td><td>the exact prompt the model saw, and the task before formatting</td></tr>
<tr><td><code>agent:turn</code></td><td>raw output, parsed content, parsed tool calls per turn</td></tr>
<tr><td><code>tool:dispatch</code></td><td>args, toolkit position, explore flag, pressure</td></tr>
<tr><td><code>tool:result</code> / <code>error</code> / <code>retry</code></td><td>result, prefill token count, duration, transient parking</td></tr>
<tr><td><code>tool:authReject</code></td><td>protected-tool denial with full lineage</td></tr>
<tr><td><code>pool:open</code> / <code>close</code> / <code>agentDrop</code></td><td>agent count, pressure snapshot, findings, drop reason</td></tr>
